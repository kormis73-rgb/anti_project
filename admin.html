구글 스프레드시트 연동 설정

기존 구글 스프레드시트의 Apps Script에 최신 코드를 배포하고 발급받은 웹 앱 URL을 입력하시면, 스프레드시트에 farms, predictions, settlements 시트가 자동으로 구성되어 실시간 양방향 연동됩니다.

구글 시트 연동 3단계 가이드
1. 구글 스프레드시트 > [확장 프로그램] > [Apps Script] 열기
2. 프로젝트 폴더 내 google-apps-script.js 코드로 교체 후 [저장]
3. 우측 상단 [배포] > [배포 관리]에서 [수정] > '새 버전'으로 선택 후 배포한 웹 앱 URL을 복사해 이곳에 입력!
