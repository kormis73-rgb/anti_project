# 🌿 S2T 계약재배 및 생산관리 시스템 (S2T Farm Management)

> **Seed-to-Table(S2T)**: 계약 농가 등록부터 정식, 착과 주기 모니터링, 수확 물량 예측, 그리고 최종 정산 및 현장 품질 이슈 관리까지 원스톱으로 지원하는 통합 스마트 생산 관리 시스템입니다.

## 📊 3대 핵심 관리 탭 기능

### ① 농가등록 탭 (회원 및 기반 정보)
- **주요 컬럼**: 농가코드, 농가명(대표자), 연락처, 지역(주소), 재배 품목(하미과멜론 / 수박 고상재배), 하우스 동수 / 면적(평), 계약 상태(계약 완료 / 검토 중), 등록일시
- **특징**:
  - 대표자/농가명 및 지역 실시간 검색
  - 품목별, 계약상태별 원클릭 필터링
  - 농가별 **[생산예측 바로등록]** 단축 버튼 제공

### ② 생산예측 탭 (S2T 핵심 데이터)
- **주요 컬럼**: 계약ID, 농가명, 재배 품목, 정식일(심은 날), 착과일(수정일), 예상 수확 시작~종료일, 수확 D-Day, 예상 출하 물량(kg / 통), 현재 생육 단계
- **🌱 S2T 생육 주기 스마트 계산기**:
  - **수박 고상재배(반촉성)**: 정식 후 착과 **35 ~ 40일 (평균 38일)** | 수정(착과) 후 수확 **45 ~ 50일 (평균 48일)**
  - **하미과멜론**: 정식 후 착과 **30 ~ 35일 (평균 33일)** | 착과 후 수확 **55 ~ 60일 (평균 58일)**
  - 정식일 입력 시 착과일(평균) 및 수확 시작·종료·평균일 자동 입력, 착과일 직접 수정 시 실시간 연동 재계산
  - D-Day 및 수확 임박(D-7 이내) 농가 실시간 뱃지 점멸 알림

### ③ 정산 및 이슈 탭 (유통 및 품질 관리)
- **주요 컬럼**: 정산ID, 계약ID, 농가명, 품목, 수확일, 실제 출하 물량, 품질 등급(특/상/중), 책정 단가(원), 예상 정산금액(원), 현장 특이사항 및 이슈
- **특징**:
  - 계약 건 선택 시 농가 및 품목, 예상 물량 자동 연동
  - 예측 물량 대비 **실제 출하 달성률(%)** 자동 산출
  - 실제 출하 물량 × 책정 단가 = **예상 정산금액 실시간 자동 계산**
  - 원클릭 퀵 태그 지원: `+ 당도 우수`, `+ 병해충 무발생`, `+ 흰가루병 방제`, `+ 야간 저온 영향`, `+ 열과 관리 우수` 등

## 🔗 기존 구글 스프레드시트와 실시간 연동 방법

앱 화면 우측 상단의 **[⚙️ 시트 연동 설정]**을 통해 기존 구글 시트를 클라우드 데이터베이스로 연결할 수 있습니다.

### 단계 1: 구글 시트 Apps Script 열기
1. 연동할 구글 스프레드시트로 접속합니다.
2. 상단 메뉴의 **[확장 프로그램]** > **[Apps Script]**를 클릭합니다.

### 단계 2: 최신 백엔드 코드 붙여넣기
1. 편집기에 열려 있는 기존 코드를 모두 지웁니다.
2. `s2t-farm-app/google-apps-script.js` 파일의 전체 코드를 복사하여 붙여넣습니다.
3. 상단 💾 **[저장 (Ctrl + S)]** 버튼을 누릅니다.

### 단계 3: 새 버전으로 배포
1. 우측 상단의 파란색 **[배포]** > **[배포 관리]** 클릭
2. 활성화된 웹 앱 항목의 우측 **[수정(연필 아이콘)]** 클릭
3. 버전 드롭다운에서 **"새 버전"** 선택
4. 하단의 **[배포]** 버튼 클릭 후 생성된 **"웹 앱 URL"**(`https://script.google.com/macros/s/.../exec`) 복사

### 단계 4: S2T 앱에 URL 등록
1. 웹 앱 화면 상단의 **[⚙️ 시트 연동 설정]** 클릭
2. 복사한 웹 앱 URL을 붙여넣고 **[연결 테스트]** 후 **[설정 저장]** 클릭!
3. 이제 구글 시트에 `farms`, `predictions`, `settlements` 3개 시트가 자동 생성되며 실시간 양방향 데이터가 연동됩니다.
